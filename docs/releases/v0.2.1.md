RabbitMA v0.2.1 fixes graph construction under small memory budgets and
supersedes v0.2.0. All v0.2.0 optimizations and automatic NUMA placement remain
available with the same `megahit` command and options.

### Fix

With a 1 GiB container limit, the default `-m 0.9` budget could cause
`seq2sdbg` to stop with `Streamed edge input unexpectedly entered compact-offset
mode`. Its fixed safety reserve could exhaust the direct-record workspace
even for a tiny input.

The safety reserve now scales for targets below 2 GiB. If a budget cannot
support direct-record bookkeeping, graph construction retains resident edges
and uses valid compact locators. Budgets of 2 GiB and above retain the
previous safety-reserve rule.

A complete-pipeline regression covers 128 MiB, 512 MiB, about 0.9 GiB and
2 GiB, checking identical final records with sequence orientation, k, flags
and coverage preserved. The same test reproduces v0.2.0's failures. Portable
release builds now run this regression on all three CPU variants and test
the glibc 2.17 baseline inside a 1 GiB container before publication.

### Binary package

Download **RabbitMA-v0.2.1-linux-x86_64.tar.gz** and its SHA-256 checksum from
the assets below. As with v0.1.0, this is a ready-to-run binary package.

- Linux x86_64, **glibc 2.17 or newer**, including CentOS 7.
- Python **3.6 or newer** available as `python3`, plus gzip and bzip2.
- Includes BMI2/POPCNT, POPCNT-only and portable CPU variants and required
  non-glibc libraries, including `libnuma`.
- No compiler, CMake, glibc upgrade or extra NUMA environment variables are
  needed for normal use.

```bash
wget https://github.com/RabbitBio/RabbitMA/releases/download/v0.2.1/RabbitMA-v0.2.1-linux-x86_64.tar.gz
wget https://github.com/RabbitBio/RabbitMA/releases/download/v0.2.1/RabbitMA-v0.2.1-linux-x86_64.tar.gz.sha256
sha256sum -c RabbitMA-v0.2.1-linux-x86_64.tar.gz.sha256
tar -xzf RabbitMA-v0.2.1-linux-x86_64.tar.gz
cd RabbitMA-v0.2.1-linux-x86_64
./megahit --test -t 4
```
